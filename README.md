 # adapt-os-major - An Adaptive Workspace That Adapts To You

**Adapt OS** is an adaptive workspace and operating system for productivity built by **Emmanuel Pobee Okpoti** in Accra, Ghana.

It is designed to help creators, students and entrepreneurs build, organize and adapt their work in one place.

### Founder
**Emmanuel Pobee Okpoti** - Builder, Accra, Ghana

### What is Adapt OS?
Adapt OS is a personal operating system that adapts to the user, not the other way around.
